RecoveryDesk Static PWA

Upload ALL 8 files in this folder to the ROOT of the GitHub repository.

Required files:
- index.html
- app.js
- styles.css
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- README.txt

No npm or Node build is required.

GitHub Pages: Settings -> Pages -> Deploy from a branch -> main -> /root -> Save.
Then add your GitHub Pages domain to Firebase Authentication -> Settings -> Authorized domains.
