RECOVERYDESK V2.4.3 — TEST CLEANUP FOLLOW-UP HOTFIX

Observed after V2.4.2:
- Legacy test documents were successfully removed (Documents count dropped to 0).
- Cleanup then stopped later with PERMISSION_DENIED.
- Console also showed a secondary "Could not clear cleanup authorization" warning.

Cause:
The cleanup removes the whole /attachments/{jobKey} branch for each test job.
Normal rules only granted writes at individual attachment child records, so a
parent-branch delete was rejected even for the Owner.

Fix:
- Adds an Owner-only parent delete rule for /attachments/{jobKey}, and only when
  the linked job is already marked testRecord=true.
- Does not make normal attachments generally deletable.
- Stops attempting to clear a temporary document cleanup authorization when no
  authorization was created during that run.
- PWA cache bumped.
